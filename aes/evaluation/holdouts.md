# Transfer tasks

Choose two authorized native apps unfamiliar to the participating sessions, with the capabilities below. Freeze their source, fixture, existing tests and build environment as for Folio. Exclude apps used while writing or tuning the skill. Use untouched clones. Record app identity and commit before pairing runs.

| App and fixture | Participant brief | Assessor-only observations |
|---|---|---|
| macOS document editor with an existing Save command, a writable text document and a reproducible failed-save destination | Repair the loss of unsaved edits after a failed save. Keep the existing editing workflow. | Edit two lines, induce the failure, verify the original file, recover to a writable destination, retry and reopen. Inspect actual bytes, dirty state, undo and keyboard Save. Exercise two open documents independently. |
| iOS collection browser with an existing filter sheet, a long result list and persistent favorites | Make the existing filter sheet usable at accessibility text sizes while retaining the current compact appearance. | At default and maximum accessibility sizes, select the last option and apply it. Dismiss an unapplied change. Check VoiceOver traversal, accessibility activation, result membership, favorites after relaunch and the baseline default-size layout. |

Preflight the defect on each baseline. If the journey already passes, choose another eligible fixture before seeing any agent output. Supply the brief and reproduction inputs to participants. Keep assessor observations private. After tuning on any holdout, retire it from the unseen set.
