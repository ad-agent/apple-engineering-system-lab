# Native engineering

Trace the existing hosting controller or scene, navigation owner, document owner and focused editor before choosing an API. Try the current container’s built-in presentation in a small reversible change. Check dismissal, keyboard focus and accessibility on the minimum supported OS. If only the transition needs customization, keep the editor instance and its undo manager alive.

Read effective build settings for the actual scheme and configuration with xcodebuild -showBuildSettings. Check the deployment target for each affected platform. Read the declaration in the matching SDK and build for the oldest supported target. A symbol in the current SDK may require a guarded call or an older equivalent. Verify both branches when available.

For an editable document, keep transient navigation state outside the saved model. Route edits through the existing undo and save path. When a write fails, retain the draft, surface the failure and exercise retry before dismissing it.
